# 윈도우(No Docker) 로컬 개발 가이드

도커가 설치되지 않은 환경에서도 **Node.js**와 **Python**이 설치되어 있으므로 직접 실행이 가능합니다.

## 🚀 1. 자동 실행 (원터치)

프로젝트 루트에 생성된 **`run_local.ps1`** 스크립트를 실행하면 백엔드와 프론트엔드가 각각 실행됩니다.

```powershell
.\run_local.ps1
```

---

## 🛠 2. 수동 실행 방법 (상세)

자동 실행이 안 되거나 디버깅이 필요할 때 사용하세요.

### A. Backend (FastAPI) 실행
1. 터미널을 열고 `backend` 폴더로 이동
   ```powershell
   cd backend
   ```
2. (최초 1회) 필수 라이브러리 설치
   ```powershell
   pip install -r requirements.txt
   ```
3. 서버 실행
   ```powershell
   # 루트의 .env 파일을 backend 폴더로 복사해두세요!
   uvicorn app.main:app --reload --port 8000
   ```
   👉 접속: http://localhost:8000/docs

### B. Frontend (Next.js) 실행
1. 새 터미널을 열고 `frontend` 폴더로 이동
   ```powershell
   cd frontend
   ```
2. (최초 1회) 패키지 설치
   ```powershell
   npm install
   ```
3. 개발 서버 실행
   ```powershell
   npm run dev
   ```
   👉 접속: http://localhost:3000

## ⚠️ 주의사항
- **환경 변수**: 루트 디렉토리의 `.env` 내용을 `backend/.env`와 `frontend/.env.local`로 복사해서 사용하세요.
- **포트 충돌**: 3000번이나 8000번 포트를 다른 프로그램이 사용 중인지 확인하세요.
