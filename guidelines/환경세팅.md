# 환경 세팅 및 커스터마이징 가이드 (Configuration Guide)

새로운 프로젝트를 시작하거나 서버 환경이 변경될 때 수정해야 할 주요 변수 목록입니다.

## 📁 1. 필수 설정 파일 목록

| 파일 경로 | 용도 | 주요 변경 항목 |
|---|---|---|
| `.env` | **최우선 수정** | DB 정보, 외부 포트, API 주소, 보안 키 |
| `docker-compose.yml` | 인프라 설정 | 컨테이너 이름, 포트 매핑, 리소스 제한 |
| `frontend/src/components/Footer.tsx` | UI 설정 | 하단 카피라이트 문구 |
| `deploy.sh` | 배포 스크립트 | Slack/Discord 알림 연동 시 수정 가능 |

---

## 🛠 2. 주요 변경 변수 (Checklist)

새 프로젝트 세팅 시 아래 항목을 순서대로 찾아 변경하세요.

### A. 네트워크 및 접속 정보 (`.env`, `docker-compose.yml`)

1. **외부 접속 포트 (Service Port)**
   - 현재: `9200`
   - 변경처: `docker-compose.yml`의 `ports` 섹션 (`"9200:3000"`)
   - 변경처: `.env`의 `NEXT_PUBLIC_SITE_URL`

2. **서버 IP 주소 (Host IP)**
   - 현재: `114.108.180.228`
   - 변경처: `.env`의 `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_SITE_URL`

3. **데이터베이스 연결 (Database)**
   - 파일: `.env`
   - 변수:
     - `DB_HOST`: IP 주소
     - `DB_USER` / `DB_PASSWORD`: 계정 정보
     - `DB_NAME`: 데이터베이스 이름

### B. 프로젝트 식별자

1. **프로젝트 이름 및 컨테이너**
   - 파일: `docker-compose.yml`
   - 항목: `container_name` (예: `cheongan-backend` -> `newproject-backend`)

2. **UI 브랜드**
   - 파일: `frontend/src/app/page.tsx`, `frontend/src/app/layout.tsx`
   - 항목: 페이지 제목(`title`), 헤더 텍스트

### C. 리소스 및 보안

1. **리소스 제한 (CPU/RAM)**
   - 파일: `docker-compose.yml`
   - 항목: `deploy.resources.limits`
   - 권장: 소규모(CPU 0.5 / RAM 512M), 대규모(CPU 2.0 / RAM 4G)

2. **JWT 및 암호화 키**
   - 파일: `.env`
   - 항목: `JWT_SECRET`, `SECRET_KEY` (반드시 운영 환경마다 다르게 설정)
